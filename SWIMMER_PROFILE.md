# Профиль пловца

Шаблон — заполните под своего пловца. Приложение не читает этот файл
программно (это справочный документ для тренера, не источник данных для
генератора), но полезно вести его рядом с журналом в приложении.

## Базовые данные

- Пол/возраст:
- Уровень на старте:
- Бассейн: (длина, есть ли разделитель на 25 м — это влияет на правило
  кратности объёма в PLAN_RULES.md)
- Стиль-фокус:
- Частота тренировок:

## Прогресс навыков

Кратко фиксировать здесь общую картину; подробный журнал по каждой
тренировке ведите во вкладке «Журнал тренировок» приложения (там же —
дистанция, что убрано и почему, заметки пловца).

## Что учесть при первом запуске

- Каталог упражнений (вкладка «Каталог упражнений») сейчас в нейтральном
  состоянии: базовые упражнения помечены «освоено», всё остальное —
  «предложено». Пройдитесь по каталогу и выставьте статусы под реальный
  уровень своего пловца.
- Настройки (вкладка «Настройки») — длина бассейна, целевой диапазон
  объёма, флаг обязательности резерва.
